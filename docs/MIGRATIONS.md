# Database Migrations

## Overview

All database migrations are located in the `migrations/` directory and use `node-pg-migrate` v8+ with TypeScript.

## Prerequisites

- PostgreSQL 17+ running
- `DATABASE_URL` environment variable set (or in `.env` file)

For macOS with Homebrew PostgreSQL 17:
```bash
export PATH="/opt/homebrew/opt/postgresql@17/bin:$PATH"
```

## Running Migrations

### Run all pending migrations
```bash
npm run migrate:up
```

### Rollback last migration
```bash
npm run migrate:down
```

### Create a new migration
```bash
npm run migrate:create migration-name
```

## Migration Files

1. **001-create-users-table.ts** - Users table with mobile number authentication
2. **002-create-abha-links-table.ts** - ABHA number linkage
3. **003-create-records-table.ts** - Medical records
4. **004-create-ai-extractions-table.ts** - OCR/AI extracted data
5. **005-create-consents-table.ts** - Time-bound sharing consents
6. **006-create-consent-records-table.ts** - Consent-record junction table
7. **007-create-audit-logs-table.ts** - Immutable audit trail

## Key Features

- **UUID Primary Keys**: Auto-generated by PostgreSQL
- **Foreign Keys**: CASCADE or SET NULL as appropriate
- **Indexes**: Optimized for common query patterns
- **CHECK Constraints**: Data validation at database level
- **Triggers**: Automatic `updated_at` timestamp updates
- **JSONB**: Flexible storage for extracted_data and metadata
